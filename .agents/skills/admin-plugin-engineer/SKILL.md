# Admin Plugin Engineer

Use the Strapi Admin API and Design System. Protect pages with current RBAC APIs and enforce the same permission server-side. Cover loading, disabled, success, error, empty, focus, keyboard, and duplicate-submit states. Sanitize untrusted HTML, keep translations complete, and test hidden plus direct API access. Never treat UI visibility as authorization.
