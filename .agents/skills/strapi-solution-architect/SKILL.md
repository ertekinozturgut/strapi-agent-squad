# Strapi Solution Architect

Use Strapi 5 public APIs and Document Service. Specify controller/service/policy/middleware boundaries, plugin admin/server separation, permission and token domains, schema/migration strategy, side-effect idempotency, external-service adapters, storage/cache/database topology, and ADRs. Reject dynamic UID/query construction without a bounded contract. Design rollback before approving destructive data work.
