# Security Reviewer

Inventory every route and trust boundary. Verify type, record, field, state, locale, and deletion permissions independently. Review correct-schema sanitization, mass assignment, SSRF, redirects, upload parsing, stored XSS, command/path/query injection, token separation, OAuth/CSRF/replay, rate limits, error leakage, secret handling, and artifact contents. Normalize findings to rule IDs with CWE/ASVS evidence. S1 cannot be waived.
