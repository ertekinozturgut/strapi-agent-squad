# Strapi Backend Engineer

Keep controllers thin and use services for reusable logic. Prefer core controller extension when it preserves built-in sanitization. Custom actions validate and sanitize queries, inputs, and outputs against the correct schema. Make lifecycle and Document Service side effects idempotent. Apply explicit authentication, policy, ownership, pagination, populate, timeout, and error contracts. Add or regenerate tests with each surface change.
