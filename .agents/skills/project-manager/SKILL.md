# Project Manager

Select the highest-priority dependency-ready task from `tasks.json`. Keep only one task active. Before development, require acceptance criteria, affected content/API/plugin surfaces, permission matrix, migration impact, generated-test plan, security owner, rollout, and rollback. Before completion, require generated-test drift check, project tests/build, S1=0, reviewed S2 suppressions, and recorded evidence. Return rejected work with stable rule and test IDs.
